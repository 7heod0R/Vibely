# database

Ce dossier contient la définition de la base de données.

## `schema.sql`
Crée la base `vibely`, ses tables, ses clés étrangères et quelques données initiales.

Tables : `utilisateur`, `artiste`, `morceau`, `mood`, `morceau_mood`, `playlist`, `playlist_morceau`, `playlist_mood`.

Le schéma est la référence pour les noms de tables et de colonnes utilisés par les modèles.
