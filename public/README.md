# public

Ce dossier contient les ressources destinées au navigateur.

- `index.php` : point d'entrée public, démarre la session et lance le routeur.
- `css/` : styles de l'application.
- `js/` : interactions JavaScript, notamment le lecteur audio.

Le navigateur passe normalement par `public/index.php` plutôt que d'appeler directement les contrôleurs.
