# views

Les vues produisent l'interface HTML à partir des variables préparées par les contrôleurs.

- `layout/` : structure commune.
- `morceau/` : catalogue et création de morceaux.
- `playlist/` : listes, détail et création de playlists.
- `utilisateur/` : connexion et inscription.
- `accueil.php` : page d'accueil.
- `explorer.php` : recherche et filtrage.

Les vues n'effectuent pas de requêtes SQL.
